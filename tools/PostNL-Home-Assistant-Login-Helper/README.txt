PostNL Home Assistant Login Helper

1. Open chrome://extensions.
2. Enable Developer mode.
3. Choose Load unpacked and select this folder.
4. Start the PostNL integration setup in Home Assistant.
5. Open the PostNL sign-in link shown by Home Assistant and sign in.
6. The extension captures the postnl://login callback automatically.
7. Click the extension icon, choose Copy callback, return to Home Assistant and paste it into the setup form.
