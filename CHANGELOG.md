# Changelog

## 0.1.0

- Eerste Home Assistant-port van PostNL for Homey v1.2.0.
- PostNL PKCE-accountkoppeling.
- Mijn Post en Mijn Pakketten data.
- Track & Trace-verrijking.
- Home Assistant sensors, binary sensors en refresh button.
- Homey Flow-triggers vertaald naar Home Assistant events.
- Lovelace-kaarten Mijn Post, Laatste poststuk, Mijn Pakketten en Mijn Bezorging.
- Poststukafbeeldingen via geauthenticeerde WebSocket API.
- HACS/HA-repositorystructuur aangescherpt; Lovelace-kaarten worden nu door de integratie zelf geserveerd en geladen.
- Hassfest- en HACS-validatie toegevoegd aan GitHub Actions.
